Menú Insieme

Aplicación web responsive para visualizar el menú digital de un restaurante en español e inglés, consumiendo datos dinámicamente desde Google Sheets.

Demo

Ver proyecto online: https://agustingiannico.github.io/menu-insieme/

Características
Menú digital responsive
Cambio de idioma (Español / English)
Datos cargados dinámicamente desde Google Sheets
Persistencia del idioma seleccionado con localStorage
Diseño adaptable para PC y dispositivos móviles
Despliegue con GitHub Pages
Tecnologías utilizadas
HTML5
CSS3
JavaScript
Google Sheets (TSV)
GitHub Pages
Cómo funciona

La aplicación obtiene los datos del menú desde una hoja de cálculo de Google Sheets publicada en formato TSV.
Cada vez que se actualiza la hoja, los cambios se reflejan automáticamente en la página web sin necesidad de modificar el código.

Objetivo del proyecto

Este proyecto fue desarrollado como una solución simple y práctica para digitalizar el menú de un restaurante mediante un código QR, permitiendo actualizar precios y productos fácilmente desde Google Sheets.
